# Obsidian AI Agent Plugin — 需求文档

> 版本: 1.0.0 | 日期: 2026-05-31 | 状态: Draft

---

## 1. 项目概述

### 1.1 项目名称

**Obsidian AI Agent** (插件 ID: `obsidian-ai-agent`)

### 1.2 项目目标

构建一个 Obsidian 插件，通过 Claude API 实现**完全替代人工操作**的 AI 智能体。用户可以在 Obsidian 内通过自然语言对话，让 AI 完成所有 Obsidian 支持的操作——包括但不限于文件管理、编辑器操控、元数据管理、工作区布局、搜索、格式化等。

### 1.3 核心理念

- **全能力覆盖**：人工能做的，AI 都能做；人工做不了的（如批量操作、跨文件分析），AI 也能做
- **零配置启动**：安装插件、输入 API Key 即可使用
- **安全优先**：危险操作有确认机制，支持 Undo
- **透明执行**：工具调用过程对用户可见可追溯

### 1.4 目标用户

| 用户类型 | 使用场景 |
|---|---|
| 知识工作者 | 快速整理笔记、生成内容、跨文件检索 |
| 研究人员 | 文献笔记管理、知识图谱构建、批量标注 |
| 写作者 | 内容创作、格式化、多文档编排 |
| 开发者 | 技术文档管理、代码片段管理、API 笔记 |
| 学生 | 课堂笔记整理、复习材料生成、知识梳理 |

## 4. 用户故事

### US-001: 快速整理笔记
> 作为一个知识工作者，我希望对 AI 说"把今天的会议笔记整理成结构化文档，加上标签和链接"，AI 能够读取我的笔记、分析内容、重新组织结构、添加适当的标签和链接、保存修改。

### US-002: 批量操作
> 作为一个研究人员，我希望对 AI 说"给所有关于机器学习的笔记加上 #ml 标签"，AI 能够搜索相关文件、逐个修改 frontmatter、报告修改结果。

### US-003: 跨文件检索
> 作为一个学生，我希望对 AI 说"找到所有提到'梯度下降'的笔记，总结它们的主要观点"，AI 能够搜索整个 vault、读取相关文件、给出综合总结。

### US-004: 内容创作
> 作为一个写作者，我希望对 AI 说"基于我的大纲笔记，帮我写一篇关于 AI 发展的文章"，AI 能够读取大纲、参考相关笔记、在编辑器中直接生成内容。

### US-005: 工作区管理
> 作为一个开发者，我希望对 AI 说"帮我打开 API 文档和测试文件，左右分屏"，AI 能够操作工作区布局。

### US-006: 日记管理
> 作为用户，我希望对 AI 说"在今天的日记里记录：完成了项目提案"，AI 能够找到或创建今天的日记、追加内容。

### US-007: 知识图谱分析
> 作为研究人员，我希望对 AI 说"分析我的笔记链接结构，找出孤立的笔记"，AI 能够分析全局链接图、识别没有链接的笔记。

### US-008: 任务追踪
> 作为用户，我希望对 AI 说"列出所有未完成的任务"，AI 能够搜索所有 checkbox、过滤未完成项、汇总展示。
